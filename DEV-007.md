# DEV-007 — Terminal Source & Behavior Validation

Status: PASS — SOURCE VALIDATION COMPLETE

## Objective

Validate the current AMRHZ.SYS terminal implementation after DEV-005 and DEV-006 without adding new capability.

## Scope

- Inspect the current terminal HTML, JavaScript, state registry, and evidence registry.
- Validate JavaScript syntax and command-dispatch structure.
- Validate the terminal behavior contract for:
  - help
  - status
  - projects
  - whoami
  - clear
  - command history
  - same-page navigation
- Verify registry dependency/load order.
- Verify the status command remains explicitly bounded to static/repository-backed evidence.
- Check for accidental scope expansion or invented runtime claims.
- Record limitations honestly.

## Non-Goals

- No backend.
- No database.
- No authentication or authorization.
- No remote shell or OS execution.
- No AI execution or autonomous agents.
- No new UI feature set.
- No external integration.
- No claim of live browser execution unless independently tested.

## Execution Rule

INSPECT → IMPLEMENT (only if required) → TEST → PASS → CHECKPOINT

No implementation change should be made unless inspection identifies a concrete defect within this task scope.
